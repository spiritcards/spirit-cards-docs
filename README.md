# Spirit Cards — Documentation

Official documentation for **Spirit Cards** (SPC) — collectible creature cards
mined by Proof-of-Work on Robinhood Chain.

- **Site:** https://spiritcards.fun
- **GitBook EN:** https://spirit-cards.gitbook.io/spirit-cards-docs
- **GitBook 中文:** https://spirit-cards.gitbook.io/spirit-cards-docs-zh
- **OpenSea:** https://opensea.io/collection/spirit-cards

## Structure

- `en/` — English site (GitBook content root)
- `zh/` — 中文 site (GitBook content root)

Each folder is a GitBook content root: `SUMMARY.md` + pages, published to GitBook.
